## 📚 Manuales y Guías de Programación

Colección de apuntes, manuales y guías prácticas sobre diversos lenguajes de programación y temas fundamentales de informática.

## 📖 Contenido

| Tema | Descripción |
|------|-------------|
| [Lenguaje C](./C_Aprender.md) | Fundamentos del lenguaje C: sintaxis, estructuras de control, funciones y más. |
| [Punteros y memoria en C](./punteros_c.md) | Guía dedicada a punteros, gestión de memoria dinámica y aritmética de punteros. |

## 🚀 Cómo usar este repositorio

Cada enlace te llevará al archivo correspondiente. Puedes navegar de forma secuencial o ir directamente al tema que te interese. Todos los documentos están escritos en Markdown para facilitar su lectura y edición.
